# 법령 RAG 검색 품질 평가 보고서

## 1. 평가 개요

본 평가는 「산업안전보건기준에 관한 규칙」 기반 RAG 시스템의 검색 품질을 검증하기 위해 수행하였다.

사용자 질문에 대해 정답 근거 조문이 검색 결과 상위에 포함되는지 확인하고, 검색 방식별 성능을 비교하여 프로젝트에 적합한 검색 모델을 선정하는 것을 목적으로 한다.

- **평가 담당:** 분석가 1
- **평가 대상:** 산업안전보건기준에 관한 규칙 PDF (2026.03.02 시행본)
- **검색 대상:** 법령 청크 684개
- **평가 데이터:** 개발용 15문항, 최종 평가용 15문항
- **검색 결과 수:** Top-5
- **정답 판정:** 검색 문서의 `article_number`와 정답 조문 일치 여부

## 2. 평가 방법

### 2.1 비교 검색 방식

| 검색 방식 | 설명 |
|---|---|
| nomic-embed-text | 기존 RAG 서비스에서 사용한 임베딩 모델 |
| BM25 | 공백 기준 토큰화를 적용한 키워드 검색 |
| bge-m3 | 별도 ChromaDB를 구성하여 평가한 임베딩 모델 |

### 2.2 평가 지표

- **Hit@1:** 검색 결과 1위에 정답 조문이 포함된 질문의 비율
- **Hit@3:** 상위 3개 검색 결과에 정답 조문이 포함된 질문의 비율
- **Hit@5:** 상위 5개 검색 결과에 정답 조문이 포함된 질문의 비율
- **MRR@5:** 상위 5개 결과에서 정답 조문이 처음 등장한 순위의 역수를 질문별로 계산한 평균

### 2.3 평가 데이터 구성

법령 기반 평가 질문 30개를 개발용 15개와 최종 평가용 15개로 분리하였다.

개발용 문항을 이용해 검색 방식을 비교하고, 선정된 모델을 최종 평가용 문항에 적용하였다.

최종 평가용 문항은 검색 방식 선정 과정에 사용하지 않았다.

## 3. 개발용 평가 결과

| 검색 방식 | Hit@1 | Hit@3 | Hit@5 | MRR@5 |
|---|---:|---:|---:|---:|
| nomic-embed-text | 0.0000 | 0.0000 | 0.0000 | 0.0000 |
| BM25 | 0.6667 | 0.8667 | 0.8667 | 0.7556 |
| **bge-m3** | **1.0000** | **1.0000** | **1.0000** | **1.0000** |

bge-m3는 개발용 15문항 모두에서 정답 조문을 검색 결과 1위에 배치하였다.

BM25는 15문항 중 13문항에서 정답 조문을 Top-5 안에 검색하였다. LAW-016(제26조), LAW-020(제31조)은 Top-5 내 검색에 실패하였다.

기존 nomic 기반 검색 환경에서는 15문항 모두 정답 조문이 Top-5에 포함되지 않았다. 저장된 청크 수(684개), 임베딩 차원(768차원), 검색 모델 설정은 확인했으나, DB 구축 시 사용된 임베딩과 현재 검색 설정의 완전한 일치 여부는 검증하지 않았다. 따라서 해당 결과만으로 nomic 모델 자체의 성능 한계를 단정하지 않는다.

## 4. 검색 방식 선정

개발용 평가 결과에 따라 **bge-m3를 최종 평가 대상 검색 모델로 선정**하였다.

선정 근거는 다음과 같다.

- 개발용 15문항에서 Hit@1 및 Hit@5 모두 1.0000 기록
- 모든 평가 질문에서 정답 조문을 1위로 검색
- 동일 평가 기준에서 다른 비교 방식보다 높은 검색 성능 기록

모델 선정 후 검색 방식과 평가 기준을 유지한 상태로 최종 평가를 수행하였다.

## 5. 최종 평가 결과

| 평가 지표 | 개발용 15문항 | 최종 평가용 15문항 |
|---|---:|---:|
| Hit@1 | 1.0000 | 1.0000 |
| Hit@3 | 1.0000 | 1.0000 |
| Hit@5 | 1.0000 | 1.0000 |
| MRR@5 | 1.0000 | 1.0000 |

bge-m3는 최종 평가용 15문항에서도 모든 정답 조문을 검색 결과 1위에 배치하였다.

따라서 **본 프로젝트의 평가 데이터와 조문 단위 정답 판정 기준에서는 bge-m3가 높은 검색 성능을 보였음**을 확인하였다.

## 6. 평가의 한계

1. **평가 데이터 규모:** 총 30문항으로, 다양한 실제 사용자 질문을 대표한다고 보기 어렵다.
2. **질문 생성 방식:** 법령 기반으로 작성한 질문이므로 실제 민원인의 구어체·오타·모호한 표현에 대한 성능은 별도로 검증하지 않았다.
3. **조문 단위 판정:** `article_number` 일치 여부를 평가하므로, 정답 조문 내부의 정확한 항·호 또는 충분한 답변 근거 포함 여부까지 보장하지 않는다.
4. **중복 정답 조문:** 서로 다른 질문이 동일 조문을 정답으로 사용하는 경우가 포함되어 있어 평가 문항 간 독립성에 한계가 있다.
5. **검색과 답변 생성의 구분:** 본 평가는 Retrieval 단계에 한정되며, LLM 답변의 정확성·환각·근거 충실성은 평가하지 않았다.
6. **비교 검색 환경:** BM25에는 공백 기준 토큰화를 사용했으며, nomic 검색 환경의 구축 모델 일치 여부에 대한 검증이 완료되지 않았다.

## 7. 결론

개발용 평가에서 bge-m3가 가장 높은 검색 성능을 기록하여 최종 평가 대상으로 선정하였다.

선정된 bge-m3는 별도로 분리한 최종 평가용 15문항에서도 Hit@1, Hit@3, Hit@5 및 MRR@5 모두 1.0000을 기록하였다.

이에 따라 **현재 법령 PDF와 평가 조건을 기준으로 bge-m3를 RAG 검색 모델로 채택할 것을 권장한다.**

다만 실제 서비스 적용 전에는 다양한 사용자 질문을 이용한 검색 품질 검증과, 검색된 근거를 활용한 LLM 답변 품질 평가가 추가로 필요하다.
