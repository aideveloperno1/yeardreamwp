# 프롬프트 개선 전후 비교

- 대상: 개발용 5문항
- 변경 사항: 답변 생성 프롬프트
- 비교 실험: before-improvement / after-improvement

| 문항 | 개선 전후 변화 | 남은 문제 |
|---|---|---|
| LAW-001 | 불필요한 부가 설명 감소 | 질문에서 확인되지 않은 작업장 조건 설명이 남음 |

## 결론
- 개선된 점: 전체적으로 불필요한 부가 설명이 감소했으나 일부 문항의 답변에 설명과 모순되는 내용이 포함되어 있음
- 남은 문제: LAW-024의 마지막 요약에서 예외 조건을 생략하여 앞선 설명과 모순 발생
- 다음 작업: 요약에서도 조건·예외를 유지하도록 프롬프트를 보완하고, 동일한 5문항으로 재평가


## 추가 보완 실험: v2

- LAW-024: 자동 평가에서 진실성·정확성 통과.
  앞선 실험에서 지적된 예외 조건 관련 모순이 없다는 판정.
- LAW-001: 자동 평가에서 진실성 검토 필요.
  제5조 관련 설명이 검증 자료에 없어 확인하지 못한 상태이며,
  확인된 사실 오류는 없음.
- 사람 검토 결과: 확인 후 기록
- 결정: 현재 프롬프트 고정, LAW-001의 부가 설명은 남은 한계로 기록

결과
LAW-024: 예외 조건을 잘못 요약하던 문제 해결
